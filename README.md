Today I work on Microsoft 365 Copilot, building AI-powered product experiences with React, TypeScript, and distributed services. Before that, I worked on Azure Communication Services with React, C#/.NET, and Azure.

I enjoy working across product UI and services, exploring ideas through prototypes, and building tools that make technical or creative work easier.
